# CodeNest

CodeNest is a collaborative code-review studio. This first build is a polished, runnable frontend foundation and product-flow prototype.

## Run locally

```powershell
npm install
npm run dev
```

Use `npm run build` for a production build check.

See `docs/PROJECT_PROGRESS.md` and `docs/AGENT_HANDOFF.md` for the implementation status and next backend phase.
